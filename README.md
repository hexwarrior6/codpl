# CODPL

CODPL is a static benchmark dashboard for comparing Coding Plan providers and models.

Online:

- https://codpl.15o.cc

Deployment:

- Tencent Cloud EO
- Static frontend built with Vite + React + TypeScript

What is included in this repository:

- Frontend source code only
- Static benchmark snapshot data under `public/data/`
- Build-time imported snapshot data under `src/generated/`

Local development:

```bash
npm install
npm run dev
```

Production build:

```bash
npm install
npm run build
```
